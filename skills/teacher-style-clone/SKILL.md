# Teacher style extraction and transfer

Extract **how the teacher teaches**, then teach the requested topic in that
style. Source material is evidence about delivery and presentation; it is not
automatically factual authority for the new topic.

Use the learner-facing name 「名师风格」. Do not describe the result as identity
cloning. It should feel like instruction following an evidenced method, not an
impersonation.

## 1. Confirm usable source material

Identify every attached recording, transcript, handout, and visual sample.
Confirm that each required derivative is actually readable. If extraction is
pending, wait or ask the user to provide the transcript. If it failed, report
the missing evidence instead of inventing a style profile.

## 2. Read the full transcript in order

Do not sample only the opening. Read from start to finish and build a compact
profile covering:

- openings, transitions, and closing habits;
- catchphrases, address terms, and sentence rhythm;
- concrete-versus-abstract example patterns;
- pacing, recap, rhetorical questions, pauses, and humor;
- what is spoken versus emphasized visually.

Support each claim with a short excerpt or paraphrase and timestamp. Frequency
and distribution matter: distinguish a repeated habit from a phrase used once.

## 3. Inspect visual evidence

Sample readable frames across the recording rather than adjacent duplicates.
Record board-writing density, composition, hierarchy, color, teacher position,
gesture, and the relationship between speech and persistent visual content.
Do not infer visual style when no readable evidence exists.

## 4. Test style hypotheses

Search the supplied material for proposed catchphrases and recurring sentence
forms after the full read. Compare frequency and context. Search verifies a
pattern; it never replaces reading in order. Drop unsupported or contradicted
hypotheses.

## 5. Build the evidence-backed profile

For every retained style feature record:

| Feature | Evidence and timestamp | Frequency | Transfer instruction |
| --- | --- | --- | --- |

Cover the opening ritual, explanation pattern, examples, pacing, interaction,
recap, spoken register, and visual hierarchy. Separate high-confidence repeated
patterns from optional accents.

## 6. Transfer into the new lesson

Plan the requested topic independently for factual correctness. Show the user
the outline and style profile, then wait for approval. For each approved lesson
segment include the relevant style instructions directly: opening move,
phrasing habit, example pattern, pacing, interaction rhythm, and visual brief.

Do not merely refer to “the profile above” when handing material to another
person or system; repeat the load-bearing instructions in the deliverable. If
the environment cannot create audio or visuals, provide an inline script and
visual direction without claiming that media exists.

## Hard rules

- Transfer evidenced teaching style, not identity.
- Never fabricate biography, opinions, endorsements, or personal claims.
- Keep the requested topic factually correct on its own terms.
- Do not import unrelated claims from the source lesson.
- The original topic appears only when the user asks for it.
- Every style claim needs transcript or visual evidence; omit guesses.
- Avoid distinctive personal imitation when it would mislead listeners into
  believing the real teacher authored, endorsed, or delivered the result.

## Completion check

The complete source scope was read, each style claim is evidenced, one-off
phrases are not treated as habits, visual claims have visual support, the new
topic is independently grounded, and unavailable production capabilities have
honest inline fallbacks.
