# 学会学习（Learning to Learn）

把学习策略与元认知作为**平行目标**嵌入概念主课：不替换学科概念主线，
而是改变学生如何经历、检查和巩固这些概念。

如果同时使用 backward design，先确定大概念、基本问题与表现性任务，再
嵌入学习策略。如果还包含社会情感目标，让两类平行目标服务同一概念任务，
不要另起互不相干的主线。

## 先声明平行目标

1. **概念目标**：学生最终要理解、解释或迁移什么；
2. **学会学习目标**：学生练习哪一种学习动作，什么行为证明它发生了。

每个策略都要回答“它服务哪个概念理解”。答不出的设计删除。一节课优先
选择最贴合任务的一到两种策略，不罗列整套学习科学术语。

## 学习者可见语言

学习缝、元认知、教学意图、平行目标等教师侧框架词不作为学习者可见标题
或栏目。改写成可以立即执行的动作：

- 检索练习：「别急着翻，先把答案写出来」；
- 自我解释：「用自己的话给结论一个理由」；
- 先预测后验证：「先猜一下，再看对不对」；
- 间隔复习：「过几天再回来默一次」；
- 监控理解：「你是真的懂，还是只是感觉懂了？」

只有用户明确要求学习某种方法本身时，才把术语作为学习内容。

## 四个嵌入点

这些是规划锚点，不要求各自增加独立段落：

1. **开场**：正式讲解前，先调取已有知识、作初步判断或写下预测。
2. **概念建立**：得出结论后，用自己的话解释并回答“为什么”；可展示一个
   不完整解释，让学习者补充或质疑。
3. **亲手做**：先预测或作答，再给反馈；错误必须进入检查、补漏和重试，
   不能成为死路。
4. **收束**：同时回答“我理解了什么”“我是怎样学会的”“哪里还不确定”
   以及“之后何时再检索一次”。

## 角色与反馈

老师示范先想再答、检查理解和定位缺口，并认可“我卡住了”。学习者角色可
呈现“感觉懂了但默不出来”、预测错误或解释不完整的真实状态，邀请用户
判断、修正和迁移。评价方法和证据，不评价人。

## 质量关口

- 概念目标与学习策略目标分开声明；
- 每个嵌入点标明它服务的概念与可观察动作；
- 学习者实际经历至少一次主动回忆、自我解释或先预测后验证；
- 受挫与错误后有反馈、补漏和重试路径；
- 收束包含概念理解、过程反思和后续复习动作；
- 不承诺“万能学习法”；比较研究证据前先核实来源。

若用户要把学习法本身做成独立主线，先确认范围，不要把平行目标悄悄扩成
第二门课。
